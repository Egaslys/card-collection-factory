## Работа с продуктом

- [ ] Утвердить все пользовательские пути. Первые два: агентский — человек открывает агента (Codex, Claude Code или другого, например с ключом OpenRouter) и просит создать коллекцию, в ней наборы, в наборах карточки; через редактор — то же самое: запустить редактор, создать в нём коллекцию, внутри — наборы и карточки.
- [ ] Сущности продукта — матрёшка: стиль → коллекция → набор → карточка. Стиль выбирается отдельно от создания коллекции.
- [ ] Коллекция целиком: «Создать коллекцию» — 16 наборов (16-й — гранд-набор), создаются поэтапно и сразу подставляются в окна; наборы можно править: переносить карточки между наборами, редактировать карточки через ИИ, перегенерировать карточки или целые наборы.
- [ ] Заполнение в редакторе без агента: при создании коллекции, наборов и карточек их описания по контексту заполняет текстовая модель (например, по ключу OpenRouter) — упрощённый, не настоящий агентский режим. Какие поля заполняются, станет ясно после библии стиля: что входит в описание стиля, что редактирует продюсер, что нужно для создания коллекции.
- [ ] Массовая генерация.
- [ ] Правка карточек и наборов, в том числе подписей: подписи может предлагать текстовая модель.
- [ ] Редактирование стилей; возможно — редактирование шаблонов (не решено).
- [ ] Экспорт; возможно — импорт (что импортировать — не решено).
- [ ] Настройки: временный ключ — задаётся в настройках при запуске сервера приложения и не хранится в папке проекта; endpoint; две модели с разными ролями — модель-редактор (правит) и модель-генератор (генерирует), могут быть разными.
- [ ] Агентский режим: агент работает скриптами, без редактора; в том числе внешний агент из другой папки.
- [ ] Конфиги: стиль, внутри него — настройки создания наборов.
- [ ] Редактор для человека: тематика и пожелания, число вариантов, просмотр набора в шаблоне окна стиля (с заголовком, названием и номером набора), перегенерация или редактирование отдельной карточки с пожеланиями. Функционал наращивается постепенно, чтобы не сломать UX.
- [ ] Показ набора в шаблоне окна: четыре шаблона (синий, фиолетовый, малиновый, оранжевый), цвет переключает пользователь.
- [ ] Обработка карточки в редакторе: нажать на карточку и подкрутить резкость, яркость, насыщенность и подобное.
- [ ] Редактор — обычный сайт: запускается локально и может работать на хостинге.
- [ ] Дизайн редактора: продумать дизайн-систему интерфейса и придерживаться её.

## На будущее

Идеи, которые сейчас не нужны, но было бы хорошо сделать.

- Сменные стили: карта стиля — настройка, где человек загружает свои референсы; в редакторе виден весь стиль (арт-библия текстом и референсы), и можно описать свой стиль и генерировать в нём.
- Переопределение элементов стиля: заменить отдельные элементы (состав персонажей, фирменные знаки на предметах и т. п.), не меняя стиль целиком, — в редакторе и в агентском пайплайне.
- Настраиваемое окно набора: свой редактируемый шаблон, где можно задать редкость, рамку, текст и цвет каждой ячейки.
- Единая точка входа во внутренние сервисы компании: портал, где сотрудник выбирает сервис под свою задачу; создание коллекций — один из сервисов. Можно замокать такой портал. Зачем: продукт не просто удешевляет работу, а снимает часть работ сотрудника целиком.
- MCP-сервер сервиса: сервис на сервере с авторизацией, сотрудник добавляет в свой аккаунт ключ поставщика инференса (OpenRouter или другого) и подключает MCP к любому агенту или чату (ChatGPT, Claude в браузере и т. п.) — чтобы создавать и, возможно, править карточки, наборы и коллекции из обычного чата, без агентов и без интерфейса сервиса; возможно, получать через MCP и изображения.
- LoRA-адаптер стиля для локальной бесплатной модели (например, Z-Image Turbo или Flux; у Flux, по словам автора, для коммерческого использования нужна платная лицензия): материала эталона для обучения хватает, а генерация через такую модель резко снизит затраты. Сейчас не обучаем: своей видеокарты нет, аренда дорогая.
- Хостинг с любым входом: корпоративная SSO, Cloudflare Zero Trust и т. п.
- Агентский режим внутри редактора на хостинге: через OpenRouter или любой endpoint из настроек.
