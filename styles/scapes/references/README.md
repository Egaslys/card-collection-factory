# Эталонные карточки Scapes

160 карточек одной летней коллекции — эталон стиля: 16 наборов по 10 карточек. Файлы — картинки карточек без рамки, 430 × 480 пикселей, без изменений относительно исходных (вместе с вшитыми метаданными). Номер карточки — в имени файла; библия стиля ссылается на карточки по этим номерам.

Столбцы: набор и его место в коллекции, место карточки в окне набора (1–10), звёзды, рамка и вид окна набора — это свойства места в окне, а не картинки; подпись — как на табличке окна, вместе с ошибками исходника. «Правка ИИ Adobe» — в файле есть подпись происхождения C2PA: Adobe Photoshop 27.0.0, действие «edited» с агентом Adobe Firefly, тип источника «compositeWithTrainedAlgorithmicMedia» (картинка собрана с участием генеративной модели). У остальных файлов метаданных о происхождении нет — по ним ничего сказать нельзя.
