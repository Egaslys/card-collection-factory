# Эталонные карточки Scapes

160 карточек одной летней коллекции — эталон стиля: 16 наборов по 10 карточек. Файлы — картинки карточек без рамки, 430 × 480 пикселей, без изменений относительно исходных (вместе с вшитыми метаданными). Номер карточки — в имени файла; библия стиля ссылается на карточки по этим номерам.

Таблица нужна и человеку, и пайплайну: по ней подбирают эталонные карточки с нужной постановкой, чтобы приложить их к запросу генерации как образец стиля.

Столбцы:

- **Набор, место, звёзды, рамка, окно** — набор и место карточки в его окне (1–10), звёзды, рамка и вид окна. Это свойства места в окне, а не картинки.
- **Подпись** — как на табличке окна, вместе с ошибками исходника.
- **Фон** — абстрактный фон с его узором, стена, обстановка (какое место) или кадр без задника; что это значит и как каждый вид устроен — [BACKGROUNDS.md](../BACKGROUNDS.md).
- **Опора** — на чём держится предмет; **положение** — как он держится; **ракурс** — откуда смотрит камера ([COMPOSITION.md](../COMPOSITION.md)).
- **Персонажи** — кто из пятерых на карточке ([CHARACTERS.md](../CHARACTERS.md)).
- **Правка ИИ Adobe** — в файле есть подпись происхождения C2PA: Adobe Photoshop 27.0.0, действие «edited» с агентом Adobe Firefly, тип источника «compositeWithTrainedAlgorithmicMedia» (картинка собрана с участием генеративной модели). У остальных файлов метаданных о происхождении нет — по ним ничего сказать нельзя.

Фон, опора, положение, ракурс и персонажи — разметка эталона по 160 карточкам; категория постановки из них выводится по таблице в [BACKGROUNDS.md](../BACKGROUNDS.md).
