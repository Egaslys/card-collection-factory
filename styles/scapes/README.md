# Scapes

Стиль коллекционных карточек: яркая объёмная рисовка мобильных казуальных игр. Здесь будет библия стиля — подробное описание каждого элемента рисовки и того, как карточки складываются в наборы, — и показательные референсы с описанием. Библия пока не написана: идёт разбор стиля.

`references/` — все 160 эталонных карточек и их указатель: набор, место в окне, звёзды, рамка, подпись.

`research/` — рабочие материалы разбора: заметки, таблицы, скрипты. Локальная папка, в Git не входит.
