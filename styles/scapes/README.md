# Scapes

Scapes — стиль коллекционных карточек: яркая объёмная рисовка в духе мобильных казуальных игр. Одна карточка — это картинка без рамки размером 430 × 480 пикселей: один крупный предмет или сцена с персонажами, чистый насыщенный цвет, мягкий свет сверху слева, гладкие скруглённые формы без обводки и без мелкой фактуры. Десять карточек складываются в набор, шестнадцать наборов — в коллекцию.

Здесь лежит библия стиля — описание каждого элемента рисовки и того, как карточки складываются в наборы и коллекцию. Она написана так, чтобы по ней можно было сгенерировать или проверить новую карточку, набор или коллекцию без эталонов. Агент следует библии строго, пока человек явно не попросил иначе: слово человека весит больше любого правила ([VISION.md](../../docs/plans/VISION.md)).

## Как читать библию

- Каждое правило помечено: **решение автора** (обязательно), **измерено** (число посчитано по 160 эталонным карточкам) или **на глаз** (наблюдение без измерения).
- У каждого факта одно место; другие документы на него ссылаются.
- Примеры — ссылки на эталонные карточки: [№107](references/card-107.png).
- Что ещё не решено или не измерено, перечислено в конце каждого документа, в разделе «Не решено и не измерено». Такие пункты — не правила.
- Фрагменты для модели генерации — по-английски, в разделах «Для промпта (англ.)». Они прошли одну пробу генерации и уточнены по ней; исправленные фрагменты ещё не проверены.
`research/` — рабочие материалы разбора: заметки, таблицы, скрипты. Есть только на машине автора, в Git не входит; библия от неё не зависит.
