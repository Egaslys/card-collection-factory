# Дизайн-система редактора

Как выглядит веб-редактор фабрики карточек: цвета, шрифты, отступы, кнопки, поля и всё, из чего собираются экраны редактора, — сетка карточек, окно набора, обработка, очередь генерации, настройки. Редактор (`editor/web/`) собран из неё: подключает `components.css` и `tokens.js` как есть.

## Как открыть доску

Доска — живая страница со всеми цветами, шрифтами и элементами в двух темах. Она читает `DESIGN.md` и картинки эталонных карточек из папки стиля, поэтому двойной щелчок по файлу не сработает: нужен локальный сервер из корня репозитория. Например, в терминале в папке проекта (на macOS и Linux Python обычно уже есть):

```
python3 -m http.server 8000 --bind 127.0.0.1
```

или любой другой статический сервер; затем в браузере — http://127.0.0.1:8000/editor/design-system/example/. Тема переключается кнопками солнца и луны в верхней панели или адресом `?theme=light` / `?theme=dark`.

## Откуда она взялась

Это переделка «Монолита» — дизайн-кода, который автор сделал для своего сайта. Из «Монолита» взята основа: формат токенов, шрифты и шкала кеглей, шкалы отступов и радиусов с правилом вложенности, кнопки-капсулы и переключатели, две темы, стекло в малых дозах, правила «да / нет» и живой подсчёт контраста. Убрано всё, что делало его портфолио: глаз-Атлас, корабль, нарисованные звёзды, зерно и бумажное стекло, тёплая бумага, сцена, панчи, HUD, плитки характеристик, карточка контактов и все тексты сайта.

Добавлено то, что нужно редактору: миниатюры карточек со значком проверки и выделением, перестановка перетаскиванием, окно набора с переключателем четырёх шаблонов, ползунки обработки, очередь генерации со стоимостью, журнал, форма настроек, ввод темы и пожеланий, сравнение вариантов, пустое состояние, загрузка и ошибка.

Цвета — фирменная палитра игровой компании, которую назвал автор: зелёный — одно главное действие на экране, светло-серый — фон, синий — выделение, фокус и ход работы, красный — ошибки. Янтарный для предупреждений выведен отдельно: в фирменной палитре жёлтого нет. Вокруг карточек — только нейтральный серый, потому что карточки оценивают по цвету.

## Как устроено

- `DESIGN.md` — **единственный источник правды**: все значения и правила, в формате [design.md](https://github.com/google-labs-code/design.md) (версия alpha). В начале файла — токены (цвета, шрифты, радиусы, отступы, компоненты), ниже — пояснения и блоки ```` ```json x-tokens ```` для того, чему в формате нет места: файлы шрифтов, тени, стекло, движение. У каждого цвета есть двойник с окончанием `-dark` для тёмной темы. Файл написан по-английски: его читают агенты, которые будут строить редактор.
- `front-matter.js` — читает начало `DESIGN.md`. Это не полный разборщик YAML, а маленький, на то подмножество, которое там используется; всё, что вне его, он отвергает с номером строки. Так система обходится без пакетов и без сети.
- `tokens.js` — превращает `DESIGN.md` в переменные CSS: `--color-*`, `--type-*`, `--rounded-*`, `--spacing-*`, `--motion-*`, `--shadow-*`, `--glass-*`, `--c-<компонент>-*`, а также классы `.type-<токен>` и подключение шрифтов. Тёмная тема включается атрибутом `data-theme="dark"` на `<html>`.
- `components.css` — сами элементы: кнопки, переключатели, поля, ползунки, значки, миниатюры, окно набора, очередь, журнал, состояния. Все значения в нём — ссылки на переменные; редактор возьмёт этот файл как есть.
- `fonts/` — четыре семейства (Unbounded, Science Gothic, Geist, Geist Mono) файлами, латиница и кириллица, с файлами лицензий. Из сети ничего не грузится.
- `example/` — доска: `index.html`, `board.js` (разделы и живые части), `board.css` (раскладка доски), `content.js` (тексты и примерные данные, без значений дизайна).

Поменяли значение в `DESIGN.md`, обновили страницу — доска и всё, что подключает `tokens.js`, показывают новое.

## Как подключить в редакторе

```html
<link rel="stylesheet" href="design-system/components.css">
<script type="module">
  import { loadDesign } from './design-system/tokens.js';
  await loadDesign();
</script>
```

Дальше разметка использует классы из `components.css` (`btn btn--primary`, `seg`, `field`, `input`, `thumb`, `badge badge--pass` и т. д.) — образцы разметки видны в `example/board.js`.
