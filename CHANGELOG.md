- 2026-10-29, Claude Code (Opus 5.5) по решению автора: **подсказки о недостающих программах.** Проверка обвязки показала: на Linux без `gio` (серверы, WSL, минимальные контейнеры) `tools/trash.mjs` не может ничего удалить. Теперь корзина называет пакет, который нужно поставить (Debian/Ubuntu — `libglib2.0-bin`, Fedora и Arch — `glib2`). `tools/agent-doctor.mjs` заранее предупреждает, не проваливая проверку, если нет `rg`, `fd`, `ast-grep`, `jq`, `yq` или, на Linux, `gio`. Проверено: `check.mjs` на macOS (41 тест) и на Linux в Docker (Debian, Node 24) до правки; ветка Linux после правки проверена имитацией пустого `PATH`.

- 2026-10-29, Claude Code (Opus 5.5) по решению автора: **подготовка проекта к работе с агентами.**
  - `AGENTS.md`: сначала раздел о проекте и список того, что не решено, затем общие правила работы агента. Разделы только для Claude Code и Codex: эти две среды выбрал автор.
  - `.claude/`: настройки, хуки и строка состояния. Хук передачи возвращает handoff `docs/plans/NEXT_SESSION.md` в контекст после сжатия. Хук журнала ведёт отчёты помощников. Ограничитель отклоняет регулярные выражения с огромным счётчиком повторов.
  - `.codex/config.toml`: Codex по умолчанию обрезает `AGENTS.md`, этот файл поднимает лимит.
  - Источник скиллов `agents/skills` и генерация их копий для обеих сред (`tools/sync-agents.mjs`). Скиллов пока нет.
  - `tools/check.mjs`, `tools/agent-doctor.mjs`, `tools/trash.mjs` и тесты к ним. Это скрипты на Node без зависимостей, стек приложения они не задают.
  - Примеры подключения MCP: Playwright для проверки веб-редактора, Tavily для поиска референсов, Context7 для документации при разработке.
  - `README.md`, `MAP.md` и `docs/plans/VISION.md` с закреплённым видением автора.
  - Стек приложения, устройство пайплайна и редактора, формат наборов, настройка провайдеров изображений и разбиение на скиллы не решены: так и записано в `AGENTS.md`.
